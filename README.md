# 學生分組系統 Student Grouping

純前端單頁應用（HTML + CSS + Vanilla JS），資料存於瀏覽器 localStorage，無需後端。

## 功能

**前台（學生／訪客）**
- 左側樹狀清單依「學年度 → 科目」選擇課程，查看該科目分組現況與未分組名單
- 學生以「姓名（帳號）+ 學號（密碼）」登入
- 學生可自行標示為組長（未分組者會自動開一組），挑選組員、標記副組長
- 各組獨立卡片呈現，組長排最前、副組長次之

**後台（老師）**
- 左側課程樹狀清單，可切換／新增／刪除課程
- 課程設定：學年度、科目、每組人數、誤差人數、分組時限
- 修課名單：匯入 .txt/.csv（標題列自動略過）、手動增刪、調整組別與組長
- 分組管理：建立空組別、新增單組、隨機分配剩餘、清除本科目所有分組
- 逾時未被挑選者自動隨機分配並標示「自動」
- 匯出 JSON / CSV（含 BOM，Excel 中文不亂碼）
- 可修改老師登入密碼（預設 `teacher123`）

## 開發

靜態檔案，直接開啟 `index.html` 或起一個本機伺服器：

```bash
python3 -m http.server 8080
```

## 檔案

- `index.html` — 容器，掛載 `#app`
- `js/script.js` — 全部邏輯與畫面渲染（事件委派）
- `css/styles.css` — 樣式，支援 RWD
